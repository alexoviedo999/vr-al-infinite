# vr-al-infinite

VR/Web Rez-clone: a fixed-rail shooter through a wireframe cyberspace
tunnel, driven by user-uploaded music.

## Status

Wayfinder map: see issue #1 (created during initial chart).

## Stack (planned)

WebXR/JS — Vite + R3F + Zustand. Dual-mode: VR on Meta Quest 3
(primary) and Quest 2 (fallback), plus desktop browser.

## Source material

Rez Infinite (Sega / Tetsuya Mizuguchi) — rail-shooter, lock-on
reticles, hits become notes in the soundtrack, 01–10 layer system,
5 Areas + Area X. vr-al-infinite aims for Rez-faithful mechanics,
then layers in visual reactivity, geometry warping, and expanded
synesthesia to push past Rez's psychedelic ceiling.
